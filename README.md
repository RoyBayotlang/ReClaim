# ReClaim
1. Create a Supabase project; run `supabase/schema.sql` in the SQL editor.
2. `cp .env.example .env` and fill in your project URL + anon key.
3. `npm install && npm run dev` — register, then click **Load demo data** on the dashboard.

Not yet built (schema/tables are ready): inspection checklist UI + photo upload, repair tasks UI, QC checklist UI, QR codes, advanced filters.
